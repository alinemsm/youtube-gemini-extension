# YouTube Gemini Extension

A Chrome extension that analyzes YouTube videos using Google's Gemini AI.

## Project Structure

- `main` branch: Clean branch for production-ready code
- `development` branch: Active development work

## Getting Started

1. Switch to the development branch: `git checkout development`
2. Copy `config.template.js` to `config.js` and add your Gemini API key
3. Load the extension in Chrome

## Development Workflow

- All development work happens on the `development` branch
- Only merge to `main` when features are complete and tested
- Keep `main` branch clean and production-ready
